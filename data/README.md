# Data

The dataset was collected on our self-built automated vending cabinet platform and is **not**
distributed with this repository (see the Data availability statement of the paper).

## Requesting access

Processed samples are available from the corresponding author on reasonable request
(Kai Xie — 500646@yangtzeu.edu.cn). Please state the intended use; requests from reviewers of
the manuscript are handled first.

## Layout expected by the scripts

```
data/
├── train_images/          3,200 scene images  +  one .txt YOLO label per image
├── val_images/              680 scene images  +  labels
└── test/                    680 scene images  (85 per class) + labels
```

Labels are standard YOLO format (`class cx cy w h`, normalised). Class order:

```
0 hks_large   1 hks_small   2 hn_can   3 jlb_can
4 kkkl_can    5 wlj_can     6 xb       7 xb_wt
```

`config/data.yaml` points at these three folders with repository-relative paths.

## Intermediate artefacts (regenerated by the scripts)

| Folder | Produced by | Content |
|---|---|---|
| `cropped_gt_train_new/` | `s00` | 3,566 GT-ROI crops, one subfolder per class |
| `cropped_gt_val_pred/` | `s01` | 746 GT-ROI validation crops |
| `cls_data_new/train`, `cls_data_new/val` | `s02` | classification split consumed by `s06` |
| `cropped_pred_final_我的GPU版/` | `s04` | 680 tight Pred-ROIs used for the final test |

> The folder name `cropped_pred_final_我的GPU版` ("my GPU version" in Chinese) is kept
> unchanged so that the released code matches the experiment that produced the reported
> numbers: `results/final_test_conf_0_01_tight_roi/summary.json` records this exact path.

## Split construction and hygiene

* Classification training/validation crops are built from **GT** boxes; final-test inputs are
  **Pred** boxes produced by the detector, which mirrors the real inference path.
* Exact-hash and perceptual-hash checks found no identical images across train/val/test.
  Only two cross-split pairs had a perceptual distance <= 4; manual inspection confirmed they
  share background/composition but not content, and both were kept.
  Run `s40_check_duplicates.py` to re-verify, `s41_export_near_duplicates.py` to inspect.
